# LeadFlow // Premium B2B Lead Data Scraper

LeadFlow is a state-of-the-art SaaS dashboard that allows B2B lead generation directly from the browser. Users can search for target industries in any city, dynamically spin up isolated PostgreSQL schemas in Supabase for each query, scrape/simulate maps contact data, view results in an interactive table, and export database contents to CSV.

Built with **ReactJS + Vite + Tailwind CSS + Supabase Client**, this application is serverless, fully responsive, and runs entirely from the frontend.

---

## Key Features

1. **Dynamic Schema Creation**: Every unique search (e.g., `gym` in `delhi`) creates a dedicated database table dynamically (e.g. `leads_gym_delhi`) in Supabase.
2. **Glassmorphic SaaS UI**: Stunning dark dashboard following design systems from Vercel, Stripe, and Linear.
3. **Interactive Data Tables**: Fast sorting, pagination, client-side filtering, and responsive fields.
4. **Export Engine**: Instant table download as structured `.csv` files.
5. **Resilient Offline Sandbox**: Automatically falls back to local storage sandbox mode if Supabase credentials are not yet configured. Includes a wizard to guide connection.

## Setup & Installation

### Prerequisite
Ensure [Node.js](https://nodejs.org) is installed on your computer.

### Step 1: Install Dependencies
Open your terminal in the `lead-data-scraper` folder and install:
```bash
npm install
```

### Step 2: Configure Supabase Database
For the frontend to dynamically create tables, you must set up 5 PostgreSQL functions (RPCs) in Supabase that bypass RLS and allow dynamic DDL.
1. Open your [Supabase Dashboard](https://supabase.com).
2. Navigate to the **SQL Editor** tab in the sidebar.
3. Click **New Query**.
4. Open the local file `supabase_setup.sql`, copy its entire content, and paste it into the Supabase editor.
5. Click **Run** at the bottom right.

### Step 3: Connect Frontend to Supabase
1. Open the `.env` file in the root of the project.
2. Replace the placeholder values with your actual project keys from Supabase (Settings > API):
```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.your-anon-key
```

### Step 4: Run Locally
Launch the local Vite hot-reload development server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

## Dynamic Table Schema
Each table generated by LeadFlow contains:
- `id` (UUID Primary Key)
- `business_name` (Text, Not Null)
- `phone_number` (Text, Nullable)
- `address` (Text, Nullable)
- `website` (Text, Nullable)
- `rating` (Numeric, e.g., 4.5)
- `category` (Text, Nullable)
- `city` (Text, Nullable)
- `created_at` (Timestamp, defaults to UTC now)

## Troubleshooting

- **"RPC function not found" Error**: This means you haven't run `supabase_setup.sql` in your Supabase SQL Editor. Run the SQL script again.
- **CORS block or network error**: Check that your `.env` values are exactly copied from the Supabase API page.
- **I don't have Supabase yet**: The app runs in a fully functional **Sandbox Mode** using `localStorage` if environment keys are missing or invalid, so you can test all features immediately!
